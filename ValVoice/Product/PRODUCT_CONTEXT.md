# ValVoice Product Context

ValVoice is a Windows desktop application built specifically for Valorant players.
Its core purpose is to convert Valorant text chat into AI-generated speech and route that speech through Valorant voice chat so teammates can hear the typed message as spoken voice.

## Workflow
Valorant Text Chat → Windows Graphics Capture + OCR → ValVoice OCR → Chat Processing → TTS / AI Voice Generation → Audio Playback → Automatic Push-to-Talk → VB-CABLE Audio Routing → Valorant Voice Chat → Teammates hear the message
